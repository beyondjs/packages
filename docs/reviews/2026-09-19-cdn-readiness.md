## Distribution boundary

The [service record](../service.md) reports a prior Engine build of Packages failing around declaration/memory work; it does not establish a complete compiled distribution. This audit did not rerun that build. Existing `Artifacts` and `Delivery` are builders and must not be described as absent. A complete npm distribution assembler equivalent to Engine's was not located in these inspected Packages paths; that is a bounded source finding, not a proof of absence in every repository.

Engine is an optional implementation reference, not a required sibling checkout. Its builder composes distribution configuration, declaration generation, resources, package manifest/exports and ZIP output; automatic npm publication is not established. Exact inspected Engine paths and cross-component provenance are retained in the suite's dated CDN source review. CDN needs the Packages contracts above rather than implicit adoption of Engine's backend/bootstrap contracts.
